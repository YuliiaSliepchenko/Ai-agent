# IT Camp Landing

Простий, але візуально солідний лендинг для літнього IT + Creative табору українською мовою.

## Файли

- `index.html` — HTML-структура сторінки з усіма секціями, 10-денною програмою та галереєю.
- `styles.css` — CSS-стилі, блакитно-жовті градієнти, анімації та адаптивна сітка.
- `script.js` — JavaScript для слайдера відгуків.

## Як подивитись попередній перегляд

### Варіант 1 (найпростіший)

1. Відкрийте файл `index.html` подвійним кліком у браузері.

### Варіант 2 (рекомендовано, через локальний сервер)

1. У терміналі перейдіть у папку проєкту.
2. Запустіть:

```bash
python3 -m http.server 5500
```

3. Відкрийте в браузері:

```text
http://localhost:5500/index.html
```

4. Щоб зупинити сервер — натисніть `Ctrl + C` у терміналі.
